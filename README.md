### 简介
我更关注真实问题、清晰结构和长期可维护的实现。页面可以简洁，但信息要完整；功能可以少，但要能用。

### 现在关注
| 方向 | 内容 |
| --- | --- |
| Web | 做清晰、实用、好维护的界面 |
| 工具 | 自动化、效率提升、流程整理 |
| 医疗信息化 | 让数据和流程更容易管理 |
| 知识整理 | 把散的内容组织成能复用的结构 |
